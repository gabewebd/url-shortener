URL Shortener Microservice

URL Shortener

How to Use:

  1. Enter a valid URL in the form above (must include http:// or https://)
  2. Click "POST URL" to get a shortened URL
  3. Use the shortened URL to redirect to your original URL

Example Usage:

POST /api/shorturl with body url=https://www.google.com

Returns: {"original_url":"https://www.google.com","short_url":1}

Visit: /api/shorturl/1 to redirect to Google

Test Links (Assumes Server Runs on Port 3000):

Redirection Examples (after creating short URLs):

1. Redirect to first submitted URL (ID 1): http://localhost:3000/api/shorturl/1

2. Redirect to second submitted URL (ID 2): http://localhost:3000/api/shorturl/2

Error Examples:

1. Invalid ID Format: http://localhost:3000/api/shorturl/abc (Should return {"error":"wrong format"})

2. Non-existent ID: http://localhost:3000/api/shorturl/999 (Should return {"error":"no short url found..."})
